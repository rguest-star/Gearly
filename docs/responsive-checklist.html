Pendekatan MOBILE-FIRST: semua gaya dasar ditulis untuk layar 320px, lalu ditingkatkan lewat @media (min-width: …). Breakpoint ditentukan berdasarkan kebutuhan layout, bukan nama device.

Checklist persyaratan

  • ✓ Navbar compact + hamburger/menu drawer di smartphone (<1024px); navbar full di desktop.
  • ✓ Search full-width di mobile; search lebih besar (maks 560px) di dalam navbar desktop.
  • ✓ Filter memakai bottom sheet di mobile/tablet; sidebar persisten di desktop (form yang sama dipindah via matchMedia 1024px).
  • ✓ Product card 1 kolom (≤399px) → 2 kolom (≥400px) → auto-fill di tablet/desktop.
  • ✓ Tabel spesifikasi tidak overflow buruk: di <768px dirender sebagai daftar label→nilai; bungkus tetap punya overflow-x:auto sbg jaring pengaman.
  • ✓ Tabel perbandingan memakai horizontal scroll dengan kolom atribut sticky-kiri + header sticky-atas.
  • ✓ Semua tombol/field ≥44px (--touch-target); item drawer & opsi filter ikut aturan ini.
  • ✓ Font dasar 16px di semua layar; nilai tabel spesifikasi 16px di mobile → terbaca tanpa zoom.
  • ✓ Tidak ada horizontal page overflow: body{overflow-x:hidden}, min-width:0 pada flex/grid child, overflow-wrap:anywhere pada sel panjang, gambar max-width:100%.
  • ✓ Gambar responsif (img{max-width:100%;height:auto}, aspect-ratio, object-fit:contain; pola srcset/sizes didokumentasikan di render.js).
  • ✓ Iklan tidak menutupi konten: slot in-flow dengan tinggi reserved; sticky ad mobile dibatasi 90px + kompensasi padding-bottom body; nonaktif di desktop.
  • ✓ Sticky element tidak menghalangi konten: body{padding-top:--h-navbar}, compare bar dihitung di padding bawah, safe-area iPhone dihormati.
  • ✓ Compare bar tetap usable di layar kecil: chip boleh digulir horizontal, tombol CTA tidak pernah tergencet (flex-shrink:0), tinggi menyusut di landscape HP pendek.
  • ✓ Product card: mobile vertikal [IMG/Brand/Name/Specs/Price/Compare]; desktop ≥1280px horizontal [IMG | Name/Brand/Specs/Price/Compare]; tinggi konsisten (line-clamp + margin-top:auto + height:100%).
  • ✓ Detail produk: desktop dua kolom [Image | Info]; mobile satu kolom vertikal nyaman; gambar utama dibatasi max-height:60vh utk landscape pendek.
  • ✓ Admin dashboard: sidebar nav di ≥1024px, drawer di mobile; tabel data pakai scroll horizontal; form multi-kolom hanya saat ada ruang.
  • ✓ Max-width container konsisten (1200/1360/1440px) — layar besar tidak membuat teks/grid melebar tanpa batas.
  • ✓ Mendukung Android & iPhone, portrait & landscape (termasuk query orientation + tinggi kecil), tablet, laptop, 1080p, 1440p, 4K.
